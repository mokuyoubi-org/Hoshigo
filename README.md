シンプルで可愛い囲碁アプリ、「星碁」がリリースされました！

**■ 主な機能**

- オンラインでリアルタイム対局
- AIとの練習対局
- 対局後の形勢分析・棋譜再生
- かわいいデザインで初心者にも優しいUI

囲碁が初めての方も、腕試ししたい方も、ぜひ星碁で対局してみてください。

- WEB版: https://hoshigo.app
- Android版: https://play.google.com/store/apps/details?id=com.mokuyoubi.Hoshigo
- もくようび: https://mokuyoubi.org
