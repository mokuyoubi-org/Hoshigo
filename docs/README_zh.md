简约可爱的围棋App「星围棋」正式上线啦！

**■ 主要功能**

- 在线实时对弈
- AI陪练对局
- 赛后形势分析、棋谱回放
- 萌系设计，新手也能轻松上手

无论是第一次接触围棋，还是想检验棋力，都欢迎来星围棋下一局！

- WEB版: https://hoshigo.app
- Android版: https://play.google.com/store/apps/details?id=com.mokuyoubi.Hoshigo
- Mokuyoubi（开发商）: https://mokuyoubi.org
